# Snake Xenia

A grid-based Snake game in C++ using SFML. Programming Fundamentals final project, FAST-NUCES Lahore. 

## Features
- Menu with 3 levels (Grass, Sand, Dirt
- Directional snake sprites, 3 fruit types
- Score and saved high score
- Sound effects and background music (mute, volume, speed-up) 

## Technologies Used 
- C++ 
- SFML 2.6.1
- Visual Studio 

## Installation and Setup
1. Clone the repo.
2. Open the .slnx in Visual Studio, platform x64.
3. Make sure the SFML include and lib paths in Project Properties point to your SFML folder.
4. Build and run from Visual Studio (F5). 


## Usage / Controls
- Arrows: move.
- 1/2/3 or Left/Right: pick level.
- Enter: start or restart.
- L: menu after game over.
- M: mute.
- [ and ]: music volume.
- P: music speed-up.
- Esc: quit.
