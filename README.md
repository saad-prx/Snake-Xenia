# Snake Xenia

A grid-based Snake game in C++ using SFML.
Programming Fundamentals final project, FAST-NUCES Lahore. 

## Features
- Menu with 3 levels (Grass, Sand, Dirt)
- Directional snake sprites, 3 fruit types
- Sprite movement
- Collision detection
- Random Fruit spawn
- Score and saved high score
- Sound effects and background music (mute, volume, speed-up) 

## Technologies Used 
- C++ 
- SFML 2.6.1
- Visual Studio 

## Installation and Setup
1. Clone the repo.
2. Open the .slnx in Visual Studio, platform x64.
3. Download SFML 2.6.1 and extract the zip file to drive C.
4. Make sure the SFML include and lib paths in Project Properties point to your SFML folder.
5. open the SFML folder, and from the bin folder, copy openal32.dll and all -d-2.dll files.
6. In the repo, open x64/debug and paste the copied .dll files.
7. from the cloned repo, copy the assets folder and paste it into x64/debug as well.
8. Build and run from Visual Studio (F5) or run "PF Group Project Snake Xenia.exe" in repo/x64/debug.
9. Have fun!


## Usage / Controls
- Arrows: move.
- 1/2/3 or Left/Right: pick level.
- Enter: start or restart.
- L: menu after game over.
- M: mute.
- [ and ]: music volume.
- P: music speed-up.
- Esc: quit.
